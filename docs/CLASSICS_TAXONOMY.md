## 二、完整性判断

**已补齐**：元曲全量、蒙学主要读本、唐诗三百首/千家诗、古文观止、大学/中庸/孟子、汉赋开篇。

**仍不完整**：

1. **宋诗**：当前数据源仓库已没有 `宋诗` 目录；96 篇是旧库，不能称全量。需要另找可靠全宋诗数据源。
2. **汉赋**：只有《归田赋》1 篇；《子虚赋》《上林赋》《两都赋》等未入库。
3. **魏晋南北朝**：仅 7 篇；缺三曹、陶谢、庾信等。
4. **明清小品/小说**：15 篇明代古文，缺清代小品与章回小说节选。
5. **经部四书五经**：已有大学、中庸、孟子、论语、诗经；缺尚书、礼记、周易、春秋。
6. **译文/注释**：13,913 篇正文已校勘，但译文仍为 0，注释仅 499 篇；这是当前最大内容缺口。
7. **人工复核**：300 篇译文/注释草案已建立流程，但必须由人复核，不能把 AI 草案标成定稿。

## 三、本轮新增数据工具

```powershell
# 元曲、蒙学、古文观止、四书等扩展数据
python tools/import_extended_classics.py --apply

# 旧库重分类 / 繁简统一 / 去重
python tools/reclassify_classics.py --apply

# 导出随安装包分发的种子（当前 9.45 MB）
python tools/export_classics_seed.py

# 300 篇译文/注释草案（AI，标记待复核）
python tools/generate_translation_drafts.py --limit 300 --single --workers 1 --resume

# 人工复核：编辑 CSV 后回写
python tools/review_translations.py --from-csv --apply
```

### 入库规则

- 正文来自公共数据/内置精校，不让 AI 生成正文；
- 统一简体、去编号、按“标题+作者+正文指纹”去重；
- 保留原 ID，用户笔记/收藏/阅读历史不丢；
- `verified=1` 仅表示正文经数据源校勘，不代表译文已人工复核；
- 译文/注释草案用 `translation_status=draft`、`annotation_status=draft` 标识，人工复核后才变 `approved`。

## 四、首启与性能

- `resources/classics_seed.json` 9.45 MB，14,579 篇，随安装包分发；
- 空库首启导入实测 **3.74 秒**；第二次启动 **0.03 秒**；
- 旧库按 ID/标题合并，不重复膨胀；
- 首次启动完成写入 `data/classics_seed_version`。

## 五、下一步优先级

3. 补尚书、礼记、周易、春秋。
