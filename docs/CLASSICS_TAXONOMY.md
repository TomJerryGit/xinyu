## 二、完整性判断

**已覆盖**：唐诗、宋词、诗经、楚辞、论语、诸子、史传、蒙学、古文、元曲、宋诗。

**仍不完整**：

1. **汉赋**：没有一级分类，也没有《洛神赋》《子虚赋》等全文。
2. **魏晋南北朝诗文**：仅有《兰亭集序》《归去来兮辞》等少量散文，缺三曹、陶谢、庾信等。
3. **明清小说/戏曲**：元曲有 59 篇，但明清传奇、小说、小品文没有独立分类。
4. **经部**：缺《尚书》《礼记》《周易》《春秋》正文；当前 38 篇多为节选。
5. **宋诗、元曲、蒙学**：本地只有有限数据，未达到全量。
6. **译文/注释**：3,090 篇译文为空，2,592 篇注释为空；这是下一阶段最大的元数据缺口。
7. **校勘等级**：2,399 篇为 `verified=1`；其余 691 篇是旧库保留，详情页不显示“已校勘”。

## 三、一次性高质量入库流程

```powershell
# 1. 备份 + 清洗旧库 + 合并本地权威缓存
python tools/curate_classics.py --apply

# 2. 修正旧库错分类（唐诗/宋词/元曲/诸子/蒙学）
python tools/reclassify_classics.py --apply

# 3. 导出随安装包分发的种子
python tools/export_classics_seed.py

# 4. 验证
python -m pytest -q
python test_runner.py
```

### 入库规则

- 只使用本地公共数据/内置精选，不联网、不伪造译文；
- 标题去掉 `1.`、`2.` 等编号；正文去掉重复的标题/作者行；
- 按“标题 + 作者 + 正文指纹”去重，保留原 ID，用户笔记/收藏不丢；
- 统一简体；古籍异体字保留（如“𫐌”不做强行替换）；
- 自动补朝代、二级分类、来源、字数、难度、是否名篇；
- 明确垃圾（空正文、AI 失败、无引用重复）才删除；有用户引用的只保留。

### 首启/旧库自动合并

`resources/classics_seed.json` 随安装包分发（2.0 MB，3,090 篇）。
`ClassicsImporter.import_bundled_seed()` 在首次启动或旧库小于 3,500 篇时按 ID/标题合并：

- 新装用户：直接得到 3,090 篇、13 类；
- 老用户：保留原 ID、笔记、收藏、阅读历史，补全分类/来源/校勘标记；
- 完成后写入 `data/classics_seed_version`，不会重复导入。

## 四、下一步建议（按优先级）

1. **补译文**：先对 300 篇名篇做人工/AI 初译 + 人工复核，不批量伪造。
2. **补注释**：优先唐诗三百首、宋词三百首、诗经、论语。
3. **补分类**：新增汉赋、魏晋南北朝、明清小品/小说、经部四书五经。
4. **补宋诗/元曲/蒙学**：网络恢复后从 chinese-poetry 拉取全量；当前本地缓存不足。
5. **质量门禁**：`verified=1` 才进入“精选”，未校勘内容在 UI 标灰/提示。
