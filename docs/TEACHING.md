# 教学功能优化与预置教案

## 结论

**可以预置，但不建议把所有 4,350 篇都做成 AI 成品教案。**

最佳方案是三级：

1. **预置/缓存**：内置 98 篇代表作 × 3 难度 = 294 份离线教案，打开秒显；
2. **按需预置**：任意一篇第一次打开时，立即用离线骨架生成并写入 `teaching_plans`，约 **27ms**；
3. **AI 增强**：只有点击「重新生成」才调用一次 AI，失败自动回落离线教案。

这样既覆盖全部文章，又不把 1.4 万份未经复核的 AI 内容塞进安装包。

## 已实现

### 后端

- 新增 `teaching_plans(classic_id, level, data, source, updated_at)` 表，按“作品 + 难度”缓存；
- `get_teaching_plan()`：预置/缓存/离线三级读取；
- `teaching_workflow()`：一次结构化 AI 调用生成完整教案，替代原来的 4 次调用（赏析、逐句、练习、知识点）；
- AI 失败/超时：自动离线兜底，不阻塞课堂；
- 离线教案只写可证明内容，不伪造译文、典故、格律。

### 教案字段

- 教学目标（初级/中级/高级不同）
- 重点提示
- 创作背景
- 逐句精讲（原句、译文、关键词、修辞、结构）
- 赏析（文本、意境、格律、文化、教学建议）
- 课堂练习（选择/填空/简答，含答案与解析）
- 课后作业
- 板书设计
- 相关作品、作者信息

### 前端

- 选择作品后自动加载预置/缓存教案，无需等待；
- 显示“预置教案 / 离线预置 / AI 生成 / 缓存”来源标识；
- 新增「重新生成」「导出教案」按钮；
- 教案可导出 Markdown；
- 教学页现在完整展示目标、重点、逐句、赏析、练习、作业、板书。

## 全量预置性能

| 方式 | 规模 | 耗时 | 结果 |
|---|---:|---:|---|
| 单篇按需 | 任意 1 篇 | 约 27ms | 写入缓存 |
| 批量离线 | 200 篇 | 0.07s | 200 份 |
| 批量离线 | 3,682 篇校勘作品 | 5.69s | 3,682 份 |
| 全部三难度 | 约 4.1 万份 | 约 17s | 数据库明显变大 |

注意：全量离线预置后本地 `classics.db` 会从约 10MB 增至 **71.8MB**。因此：
- 安装包只带 294 份精选预置（0.64MB）；
- 其余按需生成，不占安装包；
- 离线教室/无网机器可运行 `tools/warm_teaching_plans.py --limit 0` 一次性预热。

## 命令

```powershell
# 生成 98 篇代表作 × 3 难度（随安装包）
python tools/build_teaching_plans.py --limit 80

# 全量离线预热（可选，数据库会变大）
python tools/warm_teaching_plans.py --limit 0 --levels standard

# 指定三难度
python tools/warm_teaching_plans.py --limit 0 --levels beginner,standard,advanced
```

## 质量边界

- **离线预置**是教学骨架：目标、结构、练习、作业可用；逐句译文/典故仍待补充；
- **AI 生成**是增强稿：必须人工复核后才能当“定稿”；
- `verified=1` 只代表正文校勘，不代表教案已人工审核；
- 教案来源在 UI 明确标识，避免把离线模板误认为名师教案。
