# 课堂模式、学生模式与三单

## 课堂模式

入口：教学页 →「课堂模式」。

- 隐藏顶部导航与左侧栏
- 教学页全屏铺开
- 逐句字号放大
- 默认隐藏练习答案、作业、笔记
- `Esc` 退出

适用：投影/一体机/教室大屏。

## 学生模式

入口：教学页 →「学生模式」。

隐藏：

- 练习答案与解析
- 教师备注/来源参数
- 课后作业（由教师另行发放）
- 笔记列表

保留：原文、教学目标、逐句框架、课堂任务。

适用：学生平板/机房/自习。

## 三单

### 预习单

- 朗读三遍、标停顿
- 圈三个不懂的词
- 写一个真问题

### 课堂任务单

- 教学目标
- 原文
- 逐句“我的理解”留白
- 小组讨论题

### 课后作业单

- 分层作业
- 练习题目（不含答案）

导出：`导出三单` → Markdown。
打印：`打印学习单` → 浏览器打印，A4 排版。

## 教案参数化

教学页可设置：

| 参数 | 取值 |
|---|---|
| 学段 | 小学 / 初中 / 高中 |
| 课时 | 1 / 2 |
| 教材 | 部编版 / 人教版 / 苏教版 / 其他 |
| 学生水平 | 基础 / 普通 / 进阶 |
| 难度 | 初级 / 中级 / 高级 |

默认（初中/1 课时/部编版/普通）走内置预置教案；修改参数后按新参数生成/缓存。

## 教师版本

- 「编辑教案」修改目标、重点、背景、文本解读、教学建议、作业、板书
- 「保存我的版本」写入 `teaching_plan_versions`，当前缓存标记 `source=teacher`
- 「恢复预置」删除当前自定义缓存，重新读取预置/离线版本
- 版本记录保留最近 20 条

## 验收

- 课堂模式：导航隐藏、答案隐藏、字号放大
- 学生模式：答案/备注隐藏
- 三单：导出成功、打印样式正确
- 参数化：小学/初中/高中目标不同，2 课时作业不同
- 教师版本：保存后重新打开仍是“我的版本”，恢复后回到预置
