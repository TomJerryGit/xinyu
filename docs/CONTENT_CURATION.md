# 内容结构整理：元曲精简 + 古文扩充

> 执行日期：2026-10-24
> 数据来源：`data/classics.db` / `resources/classics_seed.json`
> 备份：`data/classics.db.before_curation`
> 归档：`data/archive/yuanqu_removed.jsonl`

## 一、为什么改

原库 **14,525 篇**中，元曲 **10,792 篇（74%）**，而诗词之外的古文只有 227 篇左右；分类里还有古文被错分到“魏晋南北朝 / 史部 / 子部 / 宋诗”。

结果是：文库看起来像“元曲全集”，而不是语文学习库。

## 二、元曲：10,792 → 600

保留规则（按优先级）：

1. 名篇/名句标题优先（天净沙、山坡羊、卖花刀、水仙子、西厢记、窦娥冤等），最多 150 条；
2. 45 位代表作家，每人先保留 12 首；
3. 代表作家其余作品中补足；
4. 目标总量 **600 条**。

删除 **10,192 条**：

- 主要是《全元曲》中重复的曲牌片段、无名氏作品、非代表作家作品；
- 先写入归档 `data/archive/yuanqu_removed.jsonl`，数据库备份保留；
- 不是把元曲“删光”，600 条仍覆盖关汉卿、马致远、白朴、王实甫、郑光祖、乔吉、张可久、张养浩、睢景臣等。

## 三、古文：归位 + 扩充

### 归位 16 篇

把原先错分的古文统一归入“经典散文”并标记已校勘：

- 魏晋南北朝：五柳先生传、兰亭集序、北山移文、归去来兮辞、桃花源记、谏太宗十思疏、陈情表；
- 汉赋：归田赋；
- 史部：史记·项羽本纪（节选）、资治通鉴·赤壁之战（节选）；
- 子部：劝学（节选）、鱼我所欲也、狼；
- 宋诗：赤壁赋、伤仲永；
- 经部：山市。

明清小品 15 篇并入“经典散文”，二级分类保留“明清小品”。

### 新增 20 篇教材名篇

`resources/curated_prose.json`：

诫子书、生于忧患死于安乐、得道多助失道寡助、富贵不能淫、北冥有鱼、虽有嘉肴、大道之行也、两小儿辩日、咏雪、陈太丘与友期行、穿井得一人、卖油翁、孙权劝学、河中石兽、周亚夫军细柳、与顾章书、右溪记、始得西山宴游记、墨池记、病梅馆记。

- 这次是**结构精简**，不是逐篇人工判定“艺术价值”；
- 600 条元曲仍包含曲牌片段，不等于 600 个完整剧本；
- 新增 20 篇古文尚缺译文/注释，进入后续审核队列；
- 删除条目已归档，可恢复，不是不可逆删除。
